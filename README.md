# Smart Energy SAP Billing Platform

## Übersicht

Die Smart Energy SAP Billing Platform ist ein modulares Backend-Projekt zur Verarbeitung, Analyse und Abrechnung von Smart-Meter-Daten.

Die Plattform simuliert typische Prozesse moderner digitaler Energiesysteme und ERP-Workflows. Smart-Meter-Daten werden automatisch eingelesen, analysiert und in geschäftsrelevante Informationen wie Energieberichte und Rechnungen umgewandelt.

Das Projekt kombiniert technische Energiedatenverarbeitung mit SAP-inspirierten Billing-Workflows und demonstriert, wie Software zur Unterstützung dezentraler und digitalisierter Energiesysteme eingesetzt werden kann.

---

## Features

- Verarbeitung von Smart-Meter-Daten
- Analyse von Stromverbrauch und Stromerzeugung
- Berechnung von Netzbezug und Einspeisung
- Lastprofil- und Peak-Load-Analyse
- Dynamische Strompreisberechnung
- Forecasting des Energieverbrauchs
- Automatische Report-Generierung
- Automatische Rechnungserstellung
- REST API mit Flask
- Modulare Backend-Architektur
